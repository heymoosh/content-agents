# pattern-corrected-candidate-account-slate

## Outcome

Produce one consolidated, body-free candidate-account decision packet that corrects the prior
public-access-based all-hold gate using the verified local evidence inventory. The packet is for
Muxin's decision only. It must not select canonical accounts, write canonical data, label an
account "best", or invent a universal viral score.

## Required evidence distinctions

For each recommended, held, excluded, or research-further cohort, keep these dimensions separate:

1. Source-listing winner evidence.
2. Measured relative-performance evidence and its local comparator context.
3. Stored account baseline evidence.
4. Body completeness and the resulting mechanism-analysis limit.
5. Repeat engagement evidence within the locally represented account sample.
6. Reviewed-metadata, identity/provenance, and comparison-universe gaps.

Use only aggregate or account/platform identifiers and body-free metadata. Do not reproduce post
bodies, captions, titles, hooks, transcripts, structures, or creator-specific mechanisms.

## Required deliverable

Write exactly one Markdown packet and one machine-readable JSON companion under
`docs/content-studio-program/staging/corrected-candidate-account-slate-20260825/`.

The Markdown packet must include:

- a correction of the old all-hold premise;
- platform/cohort evidence coverage;
- account-level candidate dispositions with the six evidence dimensions above;
- recommended niche, broad-platform, and format pools as separate proposals, each with caveats;
- held/rejected/research-further cohorts and concrete gaps;
- an explicit, minimal decision request for Muxin; and
- the work that can resume once she decides.

The JSON companion must encode the same facts without body text and make it possible to count
each disposition and evidence dimension deterministically.

## Boundaries

- Write only the leased staging directory.
- Do not write `data/**`, canonical ledgers, product code, task or run records, or configuration.
- Do not conduct public research unless a local evidence gap is explicitly identified; any such
  gap must be described, not silently filled.
- Do not use public-access failure as evidence that local evidence is absent.

## Acceptance criteria

- Outputs are body-free and contain no creator-specific content or rankings.
- They account for all 65 locally represented accounts and all 13 represented platforms, while
  naming Pinterest as a missing configured platform.
- They distinguish all six required evidence dimensions without collapsing them to a single score.
- They make no canonical selection and clearly ask Muxin for the exact decision needed before
  reviewed metadata or source-evidence writes.
