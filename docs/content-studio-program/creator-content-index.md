# Creator content library: index

Rolls up every per-creator file under `docs/content-studio-program/creator-content/`, one row per
creator, per the Aug. 26 direction in `broad-pattern-research-policy-20260825.md` (see "Aug. 26
direction: per-creator content library" and its "Rerun playbook"). This is the structured
handle/audience-size/media-type/topic record, plus items actually captured and a link to the full
file. It does not restate each file's content; open the linked file for verbatim posts, hooks,
structure, and framing notes.

## Known gaps (pending retry)

- **YouTube transcripts, RESOLVED Aug. 27:** the earlier session-wide Chrome-playback throttle
  (documented in `broad-pattern-research-policy-20260825.md`'s Aug. 26/27 findings) was fixed by
  switching transcript capture to `yt-dlp` directly via Bash instead of Chrome video playback,
  which reaches YouTube over plain HTTP and is immune to that throttle. All previously-blocked
  YouTube creators were completed in a follow-up pass: Ali Abdaal, Leeja Miller, LegalEagle, Johnny
  Harris (all 30/30), plus newly captured Melissa Perri (30/30), MrBeast (30/30), PewDiePie (30/30,
  23/30 with a real transcript, 7 honestly marked unavailable), and Teresa Torres (26/30, via a
  cross-channel guest-appearance capture since she has no substantial own channel). `yt-dlp` can
  still hit a softer, per-download connection-level slowdown from YouTube on large batches (seen on
  LegalEagle and PewDiePie); it self-resolves with retries, just takes longer, not a hard block.
