Human Inference · Outreach Phase 5 review

Discovery that compounds instead of repeating itself

This review shows the judgment changes before any live Scout run. Nothing here contacts a lead, drafts a pitch, schedules content, or publishes anything.

What changes in a run

Normal input → rotated lens → bounded web discovery → deterministic gates → existing Outreach review queue

Before

Broad theme search

Scout received a theme, the full fit rubric, and a list of existing names. This could drift back toward generic category searches and repeat familiar candidates.

Now

One declared search lens

Each run selects one belief, one community dialect, one modality, and a small anchor subset. The next run advances the persisted lens instead of silently rerunning the same search.

How the search prompt is sharper

Platform discovery

Generate fresh queries from the active belief, dialect, and modality. Use trusted anchors as graph entry points, not candidates to repeat. Verify fit with a direct quote and separately search for counter-evidence.

Client discovery

Start with reflective founders or executives whose public words show openness to changing direction. Establish a named person’s worldview fit first. Research the company only after that person qualifies.

Learning from decisions

Passed leads and their required reasons become negative examples. Pursue and pass rates are shown to the next run. If the frontier is cold, unchanged methodology blocks another search; changing the fit profile or worldview map permits one recalibrated run.

Deterministic gates after model output

  • Permanent frontier: Every existing lead is excluded regardless of whether it was pursued or passed. Legal suffixes, punctuation, leading “The,” and URL/domain variants canonicalize to the same identity.
  • Mid-tail policy: Podcast and newsletter audiences at or above configured caps are downgraded. Client companies at configured late funding stages are excluded.
  • Evidence gate: Client candidates require a named person’s substantive quote from a valid source before any lead is written. A missing disconfirmation pass deterministically downgrades the result.
  • Cost guard: The configured five-candidate cap applies to the whole run and model output is sliced before either write loop. Rate limits receive at most two exponential-backoff retries.
  • Run ledger: Completed and failed runs append to data/outreach/run-log.jsonl with lens, calibration, duration, searches, evidence, retries, and mid-tail outcomes.

Weekly Strategy output

The new command is read-only. It folds Outreach into the normal Strategy brief without creating a separate workflow or urgency score.
