One safe front door for fiction ideas

The Fiction room now opens on an idea inbox. It preserves the author's exact input, asks for clarification when the destination is uncertain, proposes cleanup for review, and connects landed chapters to the existing GitHub review loop.

Grok 4.5 cross-family audit: PASSAuthenticated Grok adapter: PASSFocused tests: PASSHeld for judgment review

What changed

Before

Ideas had to be manually placed into Write next or a canonical document. Studio had no conversational router, cleanup proposal, or direct chapter PR bridge.

After

Ideas enter one inbox, retain exact author bytes, receive a fail-closed destination, and wait for explicit approval. Chapter review comments can request Claude, Grok, or Codex on exact line ranges.

The normal path

1. CaptureStore the raw idea outside git, unchanged.
2. ClassifyWorld, character, plot, chapter, imagery, or clarify.
3. ReviewShow cleanup and provenance beside the original.
4. ApproveWrite one permitted document on main, or queue chapter beats.
5. ReviseUse exact GitHub comment spans, validate, commit, push, and reply.
